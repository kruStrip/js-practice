# JavaScript: мини-задачи

Небольшие задания на JavaScript: строки, файлы, DOM и калькулятор.

**Стек:** JavaScript · HTML

## Что внутри

- `calculator.html` — калькулятор
- `string_stats.js`, `swap_case.js` — работа со строками
- `file_replace.js` — замена в файле
- `news_feed.js` — лента новостей
- `print_machine.html`, `print_machine.js` — учебная страница

## Запуск

Открыть HTML-файл в браузере, Node-скрипты — через `node файл.js`.
